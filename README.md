# 🌟 Personal Portfolio Website

A clean, one-page **personal portfolio website** built using **HTML5 only**, showcasing my bio, projects, skills, and contact information.  
Designed with semantic HTML for structure, accessibility, and clarity. 💻✨

---

## 🚀 Features

- 🏷 **Semantic HTML**: Organized using `header`, `nav`, `main`, `section`, and `footer`.  
- 👤 **About Me Section**: Personal introduction with photo.  
- 📁 **Projects Section**: Highlights small projects demonstrating web development skills.  
- 🛠 **Skills Section**: Displays technical proficiency in HTML, CSS, and JavaScript.  
- ✉️ **Contact Section**: Functional form with labels and placeholders, plus social media links.
